# Login Page Project

A simple full-stack login page developed using HTML, CSS, JavaScript, Node.js, and Express.

## Features

- User login
- Email validation
- Password validation
- Backend authentication
- Success and error messages
- Dashboard
- Logout functionality

## Technologies Used

### Frontend

- HTML
- CSS
- JavaScript

### Backend

- Node.js
- Express.js
